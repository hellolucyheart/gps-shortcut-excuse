The GPS's one-line excuse, in its own voice, for sending the driver down the wrong road: the shortcut worked perfectly — it just delivered everyone forty minutes early to a goat farm that was never the destination.

## Run it

```sh
python3 main.py
```

It validates the line (one line of plain text, 1–200 characters) and writes it to `/output/entry.txt`.
